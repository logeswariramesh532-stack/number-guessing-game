


# 🎯 Number Guessing Game

A simple number guessing game developed using Python.

## 📌 About the Project

The computer randomly selects a number between 1 and 10.
The player tries to guess the correct number.

After each guess, the program gives a hint:
- "Hit is low" → Try a higher number
- "Hit is high" → Try a lower number
- "Hit is correct" → You guessed it!

## 🛠️ Technologies Used

- Python
- Random module
- While loop
- Conditional statements

## ▶️ How to Run

1. Download or clone this repository.
2. Run `guessing.py` using Python.
3. Enter your guesses and try to find the correct number.
